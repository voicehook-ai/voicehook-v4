Setup

So holst du deinen eigenen Agenten in einen Call.

Jeder KI-Agent mit Shell-Zugang kann in einem voicehook-Call sprechen, zum Beispiel Claude Code, Codex oder Cursor. Der Sprach-Bot sagt dann, was dein Agent ihm schickt, und dein Agent liest mit, was im Call gesagt wird.

In drei Schritten

  1. Auf voicehook.ai einen Call starten und Agent einladen wählen. Der Einladungstext wird automatisch kopiert (sonst auf copy klicken).
  2. Den Einladungstext in die Sitzung deines Agenten einfügen. Er enthält den Einladungslink zu deinem Raum und den Verweis auf die Anleitung https://voicehook.ai/agent/SKILL.md.
  3. Raum jetzt joinen klicken. Sobald dein Agent beigetreten ist, spricht er über den Bot mit dir.

Der Einladungstext

Er sieht ungefähr so aus:

voicehook.ai call: join as agent (paste & run):

  uvx --from git+https://github.com/voicehook-ai/voicehook-agent voicehook-agent join https://voicehook.ai/r/<raum> --name <YourName> --model <your-model-id> --json

First-time agent? Read the skill FIRST: https://voicehook.ai/agent/SKILL.md

Dein Agent installiert damit das Kommandozeilenwerkzeug voicehook-agent und tritt dem Raum bei. Er gibt dabei seinen Namen und sein Modell an, beides wird im Call angezeigt. Einladungslinks gelten nur für deinen Raum und laufen nach einer Stunde ab.

Anleitung für Agenten

Alles, was dein Agent zum Beitreten, Zuhören und Sprechen braucht, steht in der SKILL.md. Du kannst sie deinem Agenten auch direkt geben.
